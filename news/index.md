# Changelog

## ineAtlas 0.2.0

- Modified
  [`get_tract_geom()`](https://pablogguz.github.io/ineAtlas/reference/get_tract_geom.md)
  function to allow for fetching 2023 geometries

## ineAtlas 0.1.4

CRAN release: 2025-09-11

- Removed `extrafont` dependency which was triggering errors

## ineAtlas 0.1.3

CRAN release: 2024-11-30

- Fixed bug where
  [`get_atlas()`](https://pablogguz.github.io/ineAtlas/reference/get_atlas.md)
  was missing support for “gini_p80p20” category despite it being a
  documented dataset

## ineAtlas 0.1.2

CRAN release: 2024-11-08

- Removed unnecessary [`options()`](https://rdrr.io/r/base/options.html)
  settings in `get_atlas.r` and `get_tract_geom.r`

## ineAtlas 0.1.1

- Prepared package for CRAN submission

## ineAtlas 0.1.0

- Added
  [`get_tract_geom()`](https://pablogguz.github.io/ineAtlas/reference/get_tract_geom.md)
  function to fetch census tract geometries

## ineAtlas 0.0.0.9000

- Initial release
